Attention-style emotion analysis

See which words drive the emotion score.

This hosted research demo turns a chat message into simple token vectors, compares them with emotion prototypes using cosine similarity, and visualizes the highest-weight words. It demonstrates the attention idea transparently without claiming to run the repository's local trained models.

This browser demo uses a small explicit lexical vector space. It is meant to explain cosine-attention mechanics, not to replace the original trained emotion/sarcasm models or infer a person's true mental state.
